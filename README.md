# TTarot WebVer1.9

Mã nguồn website Tarot dùng Next.js, Supabase Auth, thanh toán SePay và XAH API.

Đọc `README-WEBVER1.9.md` để xem thay đổi mới nhất về Free, Plus, Pro và Pro Max.

Trước khi deploy bản này, bắt buộc chạy `docs/SUPABASE-DAILY-READING-LIMITS.sql` trong Supabase SQL Editor để bật giới hạn lượt đọc theo ngày.
