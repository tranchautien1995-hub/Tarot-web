# Tarot-2.0

UI/mobile-only update based on Tarot-1.9 Performance.

- Dark mode is the default on a fresh visit. Theme preference remains saved after the user changes it.
- A short hint appears near the theme toggle: "Đổi sang giao diện Light".
- Mobile 6/10-card spread rails can be swiped horizontally even when the gesture starts on a card.
- Mobile page vertical scrolling works when the gesture starts on a spread card or on the fanned deck.
- Touch tap still selects a card from the 78-card fan and taps a filled slot to reveal when ready; desktop drag-and-drop remains unchanged.
- Star field reduced from 150 to 75 animated stars for lower GPU load.
- Reader prompts and API routes are unchanged.
