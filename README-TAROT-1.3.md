# Tarot-1.3

Thay đổi giao diện theo luồng từng phần:

- Phần 1: Câu hỏi, cách lấy bài và thiết lập kiểu trải.
- Khi vào web chỉ hiển thị Phần 1; Phần 2 và lịch sử chưa xuất hiện.
- Nút “Tiếp tục” chuyển sang Phần 2.
- Phần 2: khu vực trải bài / xáo & bốc hoặc tự chọn bài theo chế độ đã chọn.
- Có nút “Quay lại” để trở về Phần 1 mà không tự ý sửa prompt Reader.
- Phần 3 được giữ chỗ để thiết kế sau theo yêu cầu tiếp theo.

Không thay đổi lib/prompts.ts, API đọc bài/chat hoặc lib/xah.ts.
