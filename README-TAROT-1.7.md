# Tarot-1.7

Thay đổi giao diện:

- Thêm nút menu 3 gạch cố định bên trái màn hình.
- Menu trượt từ trái gồm: **Tài khoản** và **Lịch sử trải bài**.
- **Tài khoản** mở bảng thông tin đăng nhập và nút đăng xuất; chế độ local hiển thị trạng thái local.
- **Lịch sử trải bài** được chuyển hoàn toàn vào menu, có mở lại, xóa từng trải bài và xóa toàn bộ.
- Xóa phần **Lịch sử trải bài** cũ ở cuối trang.
- Bỏ chip tài khoản cố định ở góc dưới; tài khoản được quản lý từ menu mới.

Không thay đổi prompt Reader, API đọc bài hoặc logic phân tích Tarot.
